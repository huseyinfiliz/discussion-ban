# Security Policy

## Supported versions

Security fixes for Flarum 2 are maintained on the `2.x` branch. Use the latest compatible release and keep Flarum and its dependencies up to date.

## Reporting a vulnerability

Please report security vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/huseyinfiliz/discussion-ban/security/advisories/new).

If private reporting is unavailable, email the maintainer at `mysuperuser01@gmail.com` with the subject `Discussion Ban security report`.

Include the affected extension and Flarum versions, required permissions, reproduction steps, expected behavior, and observed impact. Use test accounts and redact credentials and unrelated personal information. Please avoid publishing exploit details in a public issue before a fix is available.
